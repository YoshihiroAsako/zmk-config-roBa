## 背景

保存・下書き保護・配置比較は整った(案 A・B)。残る課題は次の 3 つ。

- 保存後に実機へ届けるまでの手順が画面にない。誤った設定(どこからも行けないレイヤー等)を書き込む前に気づく手段もない。
- 透過キー・長押しの割り当て・Windows 日本語配列での実際の文字が図から読み取りにくい。上部の表示に毎回変わらない情報が多く、英語表記も残っている。
- キーの入れ替えやコンボのレイヤー指定、マクロの順序変更に手入力が必要。

## 使い方の確認

- roBa の利用者本人が、配置を考えるとき(図を見る)、変更するとき(コピー・交換、コンボ・マクロ)、保存した直後(次の手順・設定チェック)、戻したいとき(バックアップの差分)に使う。
- 実データ: 7 レイヤー × 43 キー、5 コンボ、1 マクロ(3 行。うち `&macro_param_1to1` は編集非対応)。透過キーは 7 レイヤー中 6 レイヤーに存在。FUNCTION(1)は、どのキー・コンボ・トラックボール設定からも有効にならない(設定チェックで指摘される実例)。
- 本人が最初に触る時点: 実装後の Viewer 起動時。図の透過表示と設定チェックは保存不要で確認できる。

## 選択肢と比較

- 透過キーの「実際に効くキー」
  - A(採用): default_layer だけが有効な前提で、default_layer の割り当てを薄く表示し、前提を画面に書く。単純で誤解が少ない。
  - B: 下の全レイヤーを順に探す。複数レイヤー同時有効を前提にすることになり、実機の動きと食い違いやすい。
- 実機反映の状況表示
  - A(採用): 開発サーバーで `git status` を読み取り専用で実行し、対象 3 ファイルの未記録状態と未送信コミット数を表示する。Git 操作は行わない。
  - B: 手順を文字で出すだけ。実装は軽いが、今どこまで済んだか分からない。
- バックアップの差分
  - A(採用): バックアップ本文を読み取り専用 API で取得し、レイヤー・キー・コンボ・マクロ単位の違いを一覧化する。
  - B: 行単位の差分。DeviceTree の書式差に引きずられ、人には読みにくい。

## 推奨案

各機能を次の方針で実装する。

- UX-04: 「変更・保存」タブ先頭と保存結果に「実機へ反映するまで」の案内(5 段階)を出す。ローカル保存とキーボード図の更新は Viewer の結果、Git の状態は読み取り結果を表示する。ビルド確認と書き込みは「Viewer では確認できません」と明記し、手順書のパスを示す。
- UX-10: 診断タブに設定チェックを追加する。エラー: 存在しないレイヤー番号の参照、範囲外のコンボ位置、同じキー・同じレイヤーで重なるコンボ。注意: どこからも有効にならないレイヤー、`&to`/`&tog` で入って戻るキーがないレイヤー、default_layer の透過キー。参考: 同じレイヤー内の同じキー入力の重複。件数を上部にも表示。保存は止めない。
- UX-13: 復元ボタンを押すと、先に今のファイルとの違いを表示し、確認後に復元する。バックアップ欄を日本語化。
- UX-08: 透過キーに default_layer の割り当てを薄く表示。今のレイヤーを開くキー(default_layer の `&mo`/`&lt`)に印を付ける。レイヤー切替キーの選択時は移動先を示し、そのレイヤーへ移動するボタンを出す。
- UX-11: キー選択の検索欄に 1 文字を入れると、Windows 日本語配列でその文字が出る割り当てを先頭に表示。既存の対応表を使い、US 配列と同じ文字になる記号だけを補う。未検証の記号(`)`、`~`)は候補に出さない。
- UX-14: 本文の文字を 1px ずつ大きくする。キーの表示を「短押し」と「長押し/種類」の 2 段にする。種類(レイヤー・修飾・マウス・Bluetooth 等)ごとに色を分け、凡例を日本語で出す。
- UX-16: 上部の状態表示から「キー数」「Studio」を外し、設定チェックの件数を追加。未保存がある間は画面下に保存バー(件数・「変更を確認」・「追加済みをローカルへ保存」)を固定表示。残る英語表記(表の見出し、凡例、入力欄の読み上げ名、バックアップ欄等)を日本語に揃える。
- UX-05: キーの編集欄に「割り当てをコピー」「ここへ貼り付け」「コピー元と交換」を追加。貼り付けと交換は同じレイヤー内に限り、追加済みの変更として登録し、元に戻す操作 1 回で取り消せる。編集非対応のキーは対象外。
- UX-06: コンボの対象レイヤーをレイヤー名のチェックボックスで選ぶ(すべて外すと全レイヤー)。マクロ行に「上へ」「下へ」「複製」を追加し、実行順の説明を出す。移動は隣の行も編集可能な場合だけにし、編集非対応の行の位置を変えない。
